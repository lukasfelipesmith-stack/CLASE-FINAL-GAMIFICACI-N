🌳 Rollo 3

¿Qué significa que se ramifique?

En una presentación normal todos ven lo mismo, en el mismo orden. En una ramificada, el público decide y cada decisión lleva a una consecuencia distinta.

🚂 Lineal

El público solo mira. Se olvida rápido.

🗺️ Ramificada

El público elige, ve consecuencias y aprende del error sin riesgo.

La fórmula de cada capítulo que usamos: Situación → Observa → Decide → Consecuencias → Aprende → Reto. Así cada capítulo funciona como un nivel de juego.

🎯 Capítulo 1

Cada rama enseña algo

Gamificar no es solo poner puntos. Cada decisión debe practicar el objetivo de tu clase y dejar evidencia de lo que aprendieron.

🎯

1. Objetivo

«Al final, el estudiante podrá explicar las 4 etapas del ciclo del agua.»

🌳

2. Decisión

«Eres una gota y sale el sol. ¿Qué te pasa?» Cada opción practica una etapa.

💬

3. Retroalimentación

Cada opción explica por qué es correcta o no. Equivocarse también enseña.

    🏫 Capítulo 4

    Llevarla al salón

    1

    Sin internet (la más fácil)

    • Guarda el archivo index.html en una USB o en el computador del salón.
    • Ábrelo con doble clic: se abre en el navegador.
    • Presiona F y proyecta.
    • El grupo vota cada decisión a mano alzada.
    2

    Con enlace para los celulares

    Gratis con GitHub Pages, en 3 pasos:

    1. Crea una cuenta en github.com y una carpeta pública: botón + → New repository.
    2. Sube tu index.html: Add file → Upload files → Commit changes (es decir, guardar).
    3. Settings → Pages → elige main → Save. En 1 o 2 minutos aparece tu enlace.

    💡 La primera vez puedes pedir ayuda al área de sistemas. Después solo subes el archivo nuevo.

    ⚠️ Los puntos y logros se guardan en el celular de cada estudiante: no se suman entre todos.
